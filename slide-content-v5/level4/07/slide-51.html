Common Mistakes

Some / Any · Find the mistake in each sentence, then tap to check.Pairs: who spots it first? · 1-on-1: say the correct sentence before you reveal it.
1
I don't have some money.
I don't have any money.
Negatives use any.
في النفي نستخدم any.
2
Do you have some brothers?
Do you have any brothers?
Questions usually use any.
الأسئلة عادةً تستخدم any.
3
There are any apples in the bag.
There are some apples in the bag.
Positive sentences use some.
الجمل المثبتة تستخدم some.

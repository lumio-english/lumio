Teacher: explain this rule
This / That / These / Those
هذا / ذلك / هؤلاء / أولئك
This = one thing near me. That = one thing far from me. These = many things near me. Those = many things far from me. Near: this / these. Far: that / those. One: this / that. Many: these / those.
This = شيء واحد قريب مني. That = شيء واحد بعيد عني. These = أشياء كثيرة قريبة. Those = أشياء كثيرة بعيدة. القريب: this / these. البعيد: that / those. المفرد: this / that. الجمع: these / those.
Examples
This is my book. (near, one)
هذا كتابي. (قريب، واحد)
That is your book. (far, one)
ذلك كتابك. (بعيد، واحد)

TEACHER: EXPLAIN THIS RULE
Plurals: one -> many
الجمع: من المفرد إلى الجمع
To talk about more than one, we change the noun. Most nouns add -s. Some add -es. Some change -y to -ies. And a few irregular nouns change completely.
للحديث عن أكثر من واحد نغير الاسم. معظم الأسماء تأخذ s. بعضها يأخذ es. بعضها تتحول فيه y إلى ies. وقليل منها شاذ يتغير كلياً.
Most nouns: add -s
معظم الأسماء: نضيف s
cat → cats • book → books • car → cars
Ends in -s, -x, -ch, -sh: add -es
ينتهي بـ s أو x أو ch أو sh: نضيف es
box → boxes • watch → watches • bus → buses • dish → dishes
Consonant + y: change y -> ies
حرف ساكن + y: نحول y إلى ies
baby → babies • city → cities • fly → flies
Vowel + y: just add -s
حرف علة + y: نضيف s فقط
boy → boys • day → days • key → keys
Irregular: the word changes
شاذ: الكلمة تتغير
child → children • man → men • foot → feet • tooth → teeth • mouse → mice
Same word for one and many
نفس الكلمة للمفرد والجمع
sheep → sheep • fish → fish

Teacher: explain this rule
Verb + -ing = a noun (an activity)
الفعل + ing = اسم (نشاط)
Add -ing to a verb and it becomes the NAME of an activity, so we can use it like a noun: draw -> drawing, sing -> singing. That's why we say "I like drawing" (not "I like draw"). Spelling: run -> running (double the last letter), dance -> dancing (drop the e).
عندما نضيف ing إلى الفعل يصبح اسماً للنشاط، فنستخدمه مثل الاسم: draw (يرسم) → drawing (الرسم)، sing (يغني) → singing (الغناء). لذلك نقول I like drawing وليس I like draw. الإملاء: run → running (نضاعف الحرف الأخير)، dance → dancing (نحذف e).
Examples
I like drawing.
أحب الرسم.
Do you like singing?
هل تحب الغناء؟

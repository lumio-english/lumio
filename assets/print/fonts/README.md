# Print fonts (local copies, used only by lib/print_kit.py)

The printables never load fonts from the internet, so a rebuild looks the same on any machine.

- **Andika** (SIL International) — the early-reader font with the single-storey "a" and "g" children learn to write. Used for tracing, letter boxes and kids' words. SIL Open Font License 1.1.
- **Nunito**, **Baloo 2** — Latin text and headings. SIL Open Font License 1.1.
- **Cairo** — Arabic. SIL Open Font License 1.1.

All are latin- or arabic-subset WOFF2 files from Google Fonts. OFL text: https://openfontlicense.org

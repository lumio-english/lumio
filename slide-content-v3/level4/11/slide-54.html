Would like / Want (polite requests) · Find the mistake in each sentence, then tap to check.Pairs: who spots it first? · 1-on-1: say the correct sentence before you reveal it.
1
I would like a rice, please.
I would like some rice, please.
Rice is uncountable → some rice / a plate of rice.
الأرز لا يُعد ← some rice أو a plate of rice.
2
I would like eat pizza.
I would like to eat pizza.
Would like + to + verb.
would like + to + الفعل.
3
Do you would like a drink?
Would you like a drink?
Would starts the question -- no "do".
would تبدأ السؤال — بدون "do".

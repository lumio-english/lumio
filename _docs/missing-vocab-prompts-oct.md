## How to send them back

1. Work one batch at a time. In ChatGPT, paste **one prompt per message**, in the numbered order, and download each picture before the next one (or download the whole batch afterwards — ChatGPT names them `ChatGPT Image <date time>.png`, and sorted by time they follow the prompt order).
2. If a picture comes out wrong, regenerate that one in the same place in the order, so the order still matches the numbers. If you skip one, tell me its number.
3. Send each batch back as one zip named `batch-01.zip`, `batch-02.zip`, … (renaming the files to the target name shown, e.g. `racket.png`, is welcome but not needed — I match by order and check every picture against its prompt).
4. Each picture lands in `assets/vocab/<target file>`; decks, trial classes, the Hub and homework pick it up by name, and I rebuild the PDFs for the lessons concerned.

**Two styles.** Number 1 (Pre-A) uses the **Kids Track** style; everything else (Levels 3–6) uses the **Teen Track** style. The right style text is already inside every prompt — copy the whole grey block.

Context for each picture: the lesson and the lesson's example sentence (the picture must show that meaning). Where a word is abstract (a verb form, a time word, a linking word, a debate word) the prompt turns it into a concrete scene a teen recognises. Prompt sources: most subject sentences are reused from `_docs/level5-vocab-replace-prompts-full.md` / `_docs/level6-vocab-replace-prompts-full.md`; marked *(new wording)* where rewritten here (abstract word made concrete, a duplicate look avoided — `target.png` is already an archery target, so `goal-aim.png` is not — or text removed from the picture).

# Missing Phonics pictures (October, ready to paste)

Built 8 Oct 2026 by checking every word in `phonics-hub/<level>.json` against `assets/vocab/*.png`. **25 pictures are missing**, all in Level 1 and Level 2 Phonics; every one is NEW (no file exists anywhere in the project). Until a picture arrives, the new English Hub shows that word as a letter tile with the group's sounds lit up, so nothing looks broken.

**Not on this list (on purpose):** the sight words *the, a, to, go, we, they, was, are, all, yes*. They are taught as words, not pictures, so the Hub shows them as "sight word" cards.

## How to send them back

Same as the October vocab list: in ChatGPT paste **one prompt per message**, in the numbered order, and download each picture. Send them back as one zip (`phonics-batch-01.zip` …); renaming to the target file name is welcome but not needed, I match by order and check every picture against its prompt. Each lands in `assets/vocab/<target file>`, and the Hub, the games and the class slides pick it up by name.

All 25 use the **Kids Track** style (already inside every prompt — copy the whole grey block).

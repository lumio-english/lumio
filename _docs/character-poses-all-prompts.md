# Lumio English — every character pose, kids and teens (full-quality regeneration)

All ten human characters (five kids for Pre-A–Level 2, five teens for Level 3–6), every pose the platform uses, as complete prompts. Lumi's two sets are in `lumi-young-poses-prompts.md` and `lumi-teen-poses-prompts.md`. Save each image with the exact file name shown and send them back in batches; I trim, resize and replace them in `assets/story/characters/` (decks, trial classes, games, homework, the student dashboard, guides and manuals pick them up by name), then re-shoot the screens.

## How to generate

1. One ChatGPT image chat **per character**. First attach that character's reference file from `_docs/character-refs/` (the current welcome-hero) and generate **0 — model sheet**; keep it in the chat — it locks the design.
2. Generate the poses one by one in the same chat; re-attach the model sheet if the face or clothes start to drift.
3. Check each image: same face, hair, clothes and colours; nothing cut off at the edges; transparent background; no text.
4. Name each file exactly as shown. Generate the **welcome-hero** pose last, from the model sheet, so the new hero matches the new set.

## Rules that apply to every prompt

- Kids are drawn as children of 7–9 (big head, short limbs); teens as 13–16 with realistic proportions. Never mix the two looks.
- Modest and Gulf-appropriate: girls' hijab and long dresses/skirts stay in every pose (Sara's kid version has no hijab, as today); nothing tight or revealing; no dating or music-video cues; props are books, pencils, phones, backpacks, a game controller, a whiteboard.
- The pose is the only thing that changes. Hair, skin tone, outfit and colours are fixed by the reference image.
- Portrait 2:3 canvas with a clear margin; I crop to the site's tall-and-narrow format myself.

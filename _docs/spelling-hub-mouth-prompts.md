# Spelling Hub — Mouth-Shape Prompts for ChatGPT/DALL-E

These illustrate the mouth position for each sound used in the 4 Spelling Hub
rules (`spelling-hub/pre-a.json`), as a visual enrichment next to each rule's
existing letter/word example. Only the 5 sounds that actually appear across
the 4 rules are covered — not the full alphabet (Rule 3, the big/small "Aa"
rule, is about letter *shape*, not a new sound, so it doesn't need one).

Generate each image, save it named exactly as shown, and drop it into
`assets/spelling/`. This is a new folder — it doesn't exist yet in the repo.

**Master style (already appended to every prompt below):**
> Simple friendly cartoon close-up of a child's mouth and lower face only (no eyes, no full face, no nose), clearly showing lip shape, teeth, and tongue position for the sound. Thick clean black outlines, warm soft skin tone, bright cheerful simple coloring consistent with a children's English-learning app, plain white background, no text or letters anywhere in the image, no watermark, square 1:1 composition, friendly and warm, aimed at Arabic-speaking kids ages 4-6.

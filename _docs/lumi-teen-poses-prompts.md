# Lumi — Teen Track ("Lumi the Youth") · full pose set and prompts

**21 poses = the complete set the platform uses.** Save each image with the exact file name shown and send them back; I trim, resize and replace them in `assets/story/characters/` (teen decks, trial classes, games and the student dashboard pick them up by name).

## How to generate

1. Start a new ChatGPT image chat and **attach `lumi-hero.png`** (in the zip). Generate **0 — model sheet** first and keep it in the chat: it locks the design.
2. Generate the poses one by one **in the same chat**; re-attach the model sheet (or lumi-hero.png) if the design starts to drift.
3. Check each image: same tuft, eyes, cream belly, orange feet, navy backpack with orange trim; nothing cut off at the edges; transparent background.
4. Name each file exactly as shown (`lumi-teen-<pose>.png`).

## The character (already inside every prompt)

> Lumi, the Lumio English mascot, in its Teen Track version: a round, plump baby chick with warm golden-yellow feathers; a tall upswept tuft of three to four curved feathers on top of the head; large glossy dark-brown eyes with two white highlight dots and short dark eyelash flicks; a small rounded orange beak; soft pink oval blush on both cheeks; a big cream-coloured oval belly patch; short rounded wing-arms with three soft finger-like feather tips; short orange legs with rounded three-toed orange feet; wearing a navy-blue school backpack with orange stitching and orange straps over both shoulders. Exactly the same character, colours and proportions as the attached reference image (lumi-hero.png) — do not redesign; only the pose and expression change. Teen Track attitude: confident, upbeat and a little cool, like a friendly older classmate — never babyish.

## Style (already inside every prompt)

> Style: premium flat vector cartoon illustration, bold clean dark-brown outlines of even weight, smooth soft cel shading with gentle highlights, rich saturated but warm colours, crisp edges, consistent line quality across the whole figure. Full body, the WHOLE character inside the frame with a clear margin on every side (nothing cropped — tuft, wings, feet and backpack all visible), centred, square 1:1 canvas, high resolution (at least 1024×1024).

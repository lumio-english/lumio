## 2. Prompt conventions (use exactly)
VOCAB ICON: one subject in ~1 sentence + master style: "Simple flat vector illustration for a children's English-learning app. Bright cheerful colors, thick clean black outlines, soft rounded shapes, one centered subject, ISOLATED ON A FULLY TRANSPARENT BACKGROUND (PNG cutout, no background color, no shadow plane, no scenery behind the subject), no text or letters anywhere in the image, no watermark, square 1:1 composition, friendly and warm, aimed at Arabic-speaking kids ages 6-9. If your tool cannot export true transparency, use a plain solid white background instead so it can be removed cleanly."
NUMERALS: bold glossy bubble-letter numeral, thick black outline, bright fill (vary neighbours), 1-2 white glossy highlights near the top, fills most of frame with margin all sides, transparent, nothing else.
MONTHS: spiral-bound calendar page, seasonal scene on top, empty date grid below, no text (matches january/march/june/september/december).
PREPOSITIONS in/on/under: Lumi (yellow chick) demonstrating with a plain wooden box/table, transparent, square.
SCENES (Pre-A/L1/L2 lesson scenes): MUST use core characters with exact briefs — Sara: curly brown hair, glasses, orange cardigan and skirt. Ziad: messy dark curly hair, blue zip-up jacket, white T-shirt (not button-down), jeans. Noor: teal/orange patterned hijab, green dress. Omar: white thobe, no headscarf, curly dark hair. Hamad: white thobe, white ghutra, black agal. Named in sentence -> that character; generic boy/girl/I/you -> rotate core characters; two people -> two different characters. Style: warm children's storybook illustration matching existing Lumio scene art (semi-cel-shaded, thick outlines, warm light), 16:9, no text. Sentences must show real usage ("My teacher teaches me." not "This is my teacher.").
SHAPES/ACTIONS (L1): WITH core characters (character holding big single-colour shape cutout; character doing the action). DAYS OF WEEK: recurring wall calendar with the day's box circled, Gulf school-week logic (Sun–Thu school, Fri family gathering, Sat weekend), core characters, Arab cultural touch.
Every prompt doc labels each file NEW (no image) or REPLACE (exists). Check `assets/vocab/` first. Eslam generates and sends images back; we verify, integrate, regenerate, verify live, commit.

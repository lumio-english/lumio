## 1. How the platform is wired (the traps)
- Two lesson renderers. `present.html` (teacher tool; set `localStorage lumio_teacher=1`) shows pre-built `slide-content/<level>/<NN>/slide-NN.html` generated by `gen_slides_*.py` from `lib/deck_template_v2.py` (Pre-A/L1/L2) and `lib/deck_template_teen.py` + `lib/deck_template_teen2.py` (L3–L6, generators `gen_slides_level{3,4,5,6}_teenv2.py`). `lesson.html` + `js/lesson.js` (student prep) is separate and reads each lesson's `activities`.
- STALE BUNDLE TRAP: `js/lesson.js` reads `js/lessons-data.js` before the JSON. After ANY edit to `lessons/<level>/lessonNN.json` run `python3 gen_lessons_data_bundle.py`.
- After content changes regenerate: the level's `gen_slides_*`, `gen_lessons_data_bundle.py`, `gen_worksheets_flashcards_<level>.py`, `gen_trial_<level>.py`; then verify in a browser (Playwright, `python3 -m http.server 8799`, `loadSlide(n)`).
- Grammar Hub rule: `grammar-hub/<level>.json` existing turns on the Hub's Grammar tab; Grammar is documented to start at Level 3. L1/L2 grammar slides are passed inline as `GRAMMAR_UNITS` in `gen_slides_level1_v2.py` / `gen_slides_level2_v2.py` — never create `grammar-hub/level1.json` or `level2.json`.
- `lib/grammar_slides.py`: topic `{title,titleAr,explanation,explanationAr,examples:[{en,ar}x4]}` -> rule slide (first 2) + practice slide (last 2). Optional `rules:[{en,ar,examples:[str]}]` for multi-rule lessons (Plurals). Optional `mcq:[{q,qAr?,options[4],answer}]` -> one in-class MCQ slide each (global `checkQuizAnswer`). Inserted after vocab, before dialogue.
- Quick Check (Pre-A/L1/L2 only): L1/L2 show Arabic word only + text-only options. Pre-A deliberately unchanged (pre-literacy) — open question for Eslam.
- Assets: vocab `assets/vocab/<slug>.png` (lowercase, spaces->`-`, e.g. `open-your-book.png`, `oclock.png`); scenes `assets/vocab-scenes/<level>/NN.jpg` 1467x825, listed in each generator's `SCENE_DATA` as `(lesson, img, [bold words], "sentence")`; story backgrounds `assets/story/backgrounds/*.jpg` 1672x941; mouth shapes `assets/spelling/mouth-<sound>.png` (blends use first consonant's image).
- Image cleanup: `rembg` u2net (`U2NET_HOME=/tmp/u2net_models`; re-install with `pip install rembg --break-system-packages`), `alpha_matting=True` fg 240 / bg 10 / erode 5. Removes dark-vignette or opaque-white backgrounds and stray fragments well; OVER-CUTS thin structures (swing set) — then use manual crop: grid overlay to find fragment boundary, crop, re-center on alpha bbox, scale ~78% of canvas. Verify with corner-alpha (RGBA mode alone proves nothing) and edge-touch checks.
- Presenter: `#gameLinks` bottom-centre of the 52px nav row. Teen "guide" badge removed (`char_badge()` returns ""). Content must stay between y~124 and y~655 on the 1280x720 stage.

## 2. Prompt conventions (use exactly)
VOCAB ICON: one subject in ~1 sentence + master style: "Simple flat vector illustration for a children's English-learning app. Bright cheerful colors, thick clean black outlines, soft rounded shapes, one centered subject, ISOLATED ON A FULLY TRANSPARENT BACKGROUND (PNG cutout, no background color, no shadow plane, no scenery behind the subject), no text or letters anywhere in the image, no watermark, square 1:1 composition, friendly and warm, aimed at Arabic-speaking kids ages 6-9. If your tool cannot export true transparency, use a plain solid white background instead so it can be removed cleanly."
NUMERALS: bold glossy bubble-letter numeral, thick black outline, bright fill (vary neighbours), 1-2 white glossy highlights near the top, fills most of frame with margin all sides, transparent, nothing else.
MONTHS: spiral-bound calendar page, seasonal scene on top, empty date grid below, no text (matches january/march/june/september/december).
PREPOSITIONS in/on/under: Lumi (yellow chick) demonstrating with a plain wooden box/table, transparent, square.
SCENES (Pre-A/L1/L2 lesson scenes): MUST use core characters with exact briefs — Sara: curly brown hair, glasses, orange cardigan and skirt. Ziad: messy dark curly hair, blue zip-up jacket, white T-shirt (not button-down), jeans. Noor: teal/orange patterned hijab, green dress. Omar: white thobe, no headscarf, curly dark hair. Hamad: white thobe, white ghutra, black agal. Named in sentence -> that character; generic boy/girl/I/you -> rotate core characters; two people -> two different characters. Style: warm children's storybook illustration matching existing Lumio scene art (semi-cel-shaded, thick outlines, warm light), 16:9, no text. Sentences must show real usage ("My teacher teaches me." not "This is my teacher.").
SHAPES/ACTIONS (L1): WITH core characters (character holding big single-colour shape cutout; character doing the action). DAYS OF WEEK: recurring wall calendar with the day's box circled, Gulf school-week logic (Sun–Thu school, Fri family gathering, Sat weekend), core characters, Arab cultural touch.
Every prompt doc labels each file NEW (no image) or REPLACE (exists). Check `assets/vocab/` first. Eslam generates and sends images back; we verify, integrate, regenerate, verify live, commit.

# Lumi — Young version (kids' levels) · full pose set and prompts

**16 files = the complete set the kids' levels use** (15 prompts — `lumi-hero.png` and `lumi-welcome-hero.png` are the same image). Save each image with the exact file name shown and send them back; I trim, resize and replace them in `assets/story/characters/` (kids' decks, trial classes, games, homework, the student dashboard and the manuals pick them up by name).

## How to generate

1. Start a new ChatGPT image chat and **attach `lumi-hero.png`** (in the zip). Generate **0 — model sheet** first and keep it in the chat: it locks the design.
2. Generate the poses one by one **in the same chat**; re-attach the model sheet (or lumi-hero.png) if the design starts to drift.
3. Check each image: same tuft, big eyes, cream belly, orange feet, black backpack with orange trim; nothing cut off at the edges; transparent background.
4. Name each file exactly as shown (`lumi-<pose>.png`).

# Noor — Young version (kids' levels) · full pose set and prompts

**17 files = the complete set the Pre-A · Level 1 · Level 2 lessons use.** Save each image with the exact file name shown and send them back; I trim, resize and replace them in `assets/story/characters/` (decks, trial classes, games, homework, the student dashboard, guides and manuals pick them up by name).

## How to generate

1. Start a new ChatGPT image chat and **attach `noor-welcome-hero.png`** (in the zip). Generate **0 — model sheet** first and keep it in the chat: it locks the design.
2. Generate the poses one by one **in the same chat**; re-attach the model sheet (or the reference image) if the design starts to drift.
3. Check each image: same face, hair, skin tone, clothes and colours; nothing cut off at the edges; transparent background; no text.
4. Name each file exactly as shown (`noor-<pose>.png`). Generate **1 — welcome-hero** from the model sheet so the new hero matches the new set.

Do the homework

Guide 5 · after every live class · unlocks the next lesson
الدليل ٥ · بعد كل حصة مباشرة · يفتح الدرس التالي
🔗 lumiooo.com  ·  or scan the code at the bottom
1
After class: Today's mission → 📝 Do homeworkIt opens as soon as the teacher marks the student present.
بعد الحصة: مهمة اليوم ← 📝 Do homeworkيُفتح الواجب بمجرد أن يسجّل المعلّم حضور الطالب.
2
Follow the steps at the topSpelling → Draw (teens: Talk) → Say It → Phonics/Grammar → Quiz. A tick shows each finished step.
اتبعوا الخطوات في الأعلىالتهجئة ← الرسم (للمراهقين: المحادثة) ← النطق ← الأصوات/القواعد ← الاختبار. علامة ✓ تظهر عند إنهاء كل خطوة.
3
Draw itYounger levels draw the word with the colours; teen levels practise a short conversation instead.
ارسموا الكلمةالمستويات الصغيرة ترسم الكلمة بالألوان، ومستويات المراهقين تتدرب على محادثة قصيرة بدلاً من ذلك.
4
Say It — tap RecordListen, say each word, record yourself. Parents: listen together and tick the box.
النطق — اضغطوا Recordاستمعوا، ردّدوا كل كلمة، وسجّلوا أصواتكم. أولياء الأمور: استمعوا مع الطفل وضعوا علامة ✓.
5
Finish the quiz → ✓ Submit HomeworkSpelling and the quiz must be tried before it can be sent.
أكملوا الاختبار ← ✓ Submit Homeworkيجب تجربة التهجئة والاختبار قبل الإرسال.
6
Homework complete!Stars for the work, and the teacher sees the results.
اكتمل الواجب!نجوم على الإنجاز، والمعلّم يرى النتائج.
7
Why it matters: the next class stays 🔒Until the homework is done, the next class shows “Finish the homework… before joining” instead of the Join button.
لماذا هو مهم: الحصة التالية مقفلة 🔒حتى يُنجز الواجب، تظهر الحصة التالية برسالة «أكملوا الواجب قبل الدخول» بدلاً من زر الدخول.
8
Done ✓ — Join on Teams is backThe next lesson's prep opens too, and so does this lesson's part of the bonus game.
📘 Guide 1 · Lesson prep📘 Guide 6 · Bonus game
تم ✓ — عاد زر الدخول إلى Teamsويُفتح تحضير الدرس التالي، وجزء هذا الدرس في لعبة المكافأة.

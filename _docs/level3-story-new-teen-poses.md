# Level 3 Story — New Teen Poses (60 poses: 10 x 6 characters)

The existing teen cast only has 11-13 poses each (wave, happy, point, think,
thumbs, surprised, celebrate, look-left, look-right, explain, welcome-hero,
plus Ziad's gaming/headphones and Hamad's extra welcome). That's not enough
variety for a 40-page story ("The Crew"), so this adds 10 new poses per
character, picked to match specific beats in the story: sitting/studying,
texting, walking to school, running a race, a big laugh, a shrug, a nervous
new-kid moment, carrying a backpack, reading, and a high-five.

Save each one named exactly as shown and drop into
`assets/story/characters/`. Same conventions as every other character batch:
transparent background, no text/watermark, portrait orientation, character
fills the frame.

Everything a student can do on Lumio

42 functions, all present in each direction. New = added this week.

Today

  1. Today's mission (next step)
  2. Lesson prep: 9 activity types, record your voice
  3. Interactive homework (draw, record, spell, quiz)
  4. Homework sheet (PDF)
  5. Writing sheet (PDF)
  6. Flashcards (PDF)
  7. Lesson trail: prep → class → homework

My adventure

  1. 3D adventure map of 20 lessons (or a list)
  2. Level progress and lessons done
  3. Level test (30 questions, 70% to pass)
  4. Certificate

My progress

  1. Totals: finished, attended, attendance, prep, homework, teacher grade New
  2. My lessons: scores per class + go back to any finished prep, homework, flashcards, sheets New

Unlocked for you

  1. Lumi's Magic Map story (4 parts)
  2. Level game

My classes

  1. Next class + Join link
  2. Upcoming classes, Cancel up to 30 min before
  3. Book one class: day, hour (Saudi + your time New), teacher
  4. Fixed weekly schedule
  5. Rate your teacher
  6. Sessions left

English Hub

  1. Vocabulary + Word Pop, Word Builder, Memory Match
  2. Grammar
  3. Idioms
  4. Phonics
  5. Spelling
  6. Songs
  7. Writing & Speaking

Rewards

  1. Reward points + Redeem (50 → +1 hour)
  2. Badges (8)
  3. Study buddies
  4. Daily streak

More

  1. Level manual (PDF)

Menu / account

  1. My profile: photo, details, subscription, payments, level test, grades, performance report
  2. Messages and notifications
  3. Guides
  4. Referrals: invite friends, free sessions
  5. Parent guide tour (Arabic + English)
  6. Avatar picker
  7. Sound effects and music on/off
  8. Kid look / Teen night look (by level)
  9. Log out
Built with three.js r128, GSAP 3.12 + ScrollTrigger and lottie-web 5.12 (Lumio's own Lottie animations in assets/lottie/). Demo data only: nothing here reads or changes real student records.
